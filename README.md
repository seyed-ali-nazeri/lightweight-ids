🛡️ Lightweight Python IDS/IPS
A simple and efficient Intrusion Detection System (IDS) and Intrusion Prevention System (IPS) built with Python.
The application monitors network traffic, detects suspicious behavior, and can automatically block malicious IP addresses in real time.

🔍 Features :

1.Real-time packet monitoring
2.IDS mode (alerts only)
3.IPS mode (automatic blocking)
4.Detection of common threats:
  Port scanning
  Brute-force patterns
  DoS/DDoS indicators
  Packet anomalies
5.Custom rule support
6.Detailed logging of events
7.Lightweight and easy to extend

🚀 Installation

git clone https://github.com/seyed-ali-nazeri/lightweight-ids.git
cd lightweight-ids
pip install -r requirements.txt
